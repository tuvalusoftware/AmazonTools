Email setup for qmodeler.net

For the Admin managing the domain and Google Workspace. Once done, send the “Send to Dev” section below over a private channel (not a public chat).

Admin performs these steps

Configuration steps

Goal: create a dedicated sending mailbox (e.g. noreply@qmodeler.net) and an App Password the app uses to send mail via SMTP on that mailbox's behalf.

  1. 1

    Create the sending mailbox in Google Workspace

    Create a new user, e.g. noreply@qmodeler.net, dedicated to automated sending — don't reuse a personal mailbox.

    admin.google.com → Directory → Users
  2. 2

    Enable 2-Step Verification on that account

    An App Password can only be created once 2-Step Verification is on.

    myaccount.google.com → Security → 2-Step Verification
  3. 3

    Create an App Password

    Sign in as noreply@qmodeler.net, create an App Password of type "Mail" / "Other". Google shows a 16-character string once — copy it immediately.

    myaccount.google.com/apppasswords
  4. 4

    Add an SPF record for the domain

    Authorizes Gmail to send on behalf of qmodeler.net, so outgoing mail isn't flagged as spam. Add the TXT record from the table below at the domain's DNS provider.

    qmodeler.net DNS provider
  5. 5

    Send the config to dev

    Copy the env block at the bottom of this page, fill in the missing value, and send it to the dev over a private channel (password manager, encrypted DM — not plain email or group chat).

DNS records to add

Add these at the DNS zone for qmodeler.net. If the domain already uses Google Workspace to receive mail (MX records set up), only the SPF row is needed.

TypeHostValueTTL
TXT @ v=spf1 include:_spf.google.com ~all 3600
TXT (recommended) _dmarc v=DMARC1; p=none; rua=mailto:admin@qmodeler.net 3600
!

If qmodeler.net already has another v=spf1 … TXT record (e.g. from Mailchimp or SendGrid), don't add a second one — merge include:_spf.google.com into the existing record instead. Multiple SPF records make the whole SPF check invalid.

Send to Dev

Fill in the value marked <...> and send this whole block to the dev. It goes straight into the project's .env file.

SMTP environment variables

paste into .env 
# Google Workspace — qmodeler.net sending mailbox
SMTP__HOST=smtp.gmail.com
SMTP__PORT=587
SMTP__USER=noreply@qmodeler.net
SMTP__PASSWORD=<16-character App Password, no spaces>
SMTP__FROM_ADDR=noreply@qmodeler.net
Select it, then ⌘/Ctrl + C to copy

Note: SMTP__PASSWORD is the App Password from step 3 — not the login password for noreply@qmodeler.net.
